# 用例（虚构数据）

编号仅用于文档，不对应自动测试 ID。

## UC-01 顾客购买非处方药

1. 用户 `user01` 浏览可售药品（`medicine.stock` 为可售批次聚合）。
2. 加入购物车并结算，选择本人地址。
3. 系统按 FEFO 预占批次，订单 `PENDING_PAYMENT`，30 分钟内模拟支付。
4. 支付成功确认出库 → 管理员接单/打包/派骑手 → 完成。

失败：无地址、购物车不属于本人、可售库存不足、超时未支付释放预占。

## UC-02 处方药

1. 结算含处方药时必须上传真实 PDF/JPEG/PNG。
2. 订单 `PENDING_REVIEW`，此时不预占。
3. 药师批准后预占成功 → `PENDING_PAYMENT`；库存不足 → `CLOSED_STOCK_SHORTAGE`；拒绝必须填原因。

失败：伪造扩展名、越权下载返回不泄露存在性的拒绝。

## UC-03 采购进货

1. 采购员创建 `DRAFT` 采购单。
2. 管理员批准 → `APPROVED`，或拒绝并写原因 → `REJECTED`。
3. 仓库录入批号、效期、合格/拒收数量。合格数生成可售批次；未收齐为 `PARTIALLY_RECEIVED`。

失败：非草稿审批、收货超过未收数量、生产日期不早于效期。

## UC-04 盘点对账

1. 仓库创建盘点 `DRAFT` → `COUNTING` → 录入实盘 → `COMPLETED`。
2. 差异追加 `STOCK_COUNT` 流水，同一单不能完成两次。
3. 对账页只读列出 `medicine.stock` 与可售批次合计的差异，不自动修正。

## UC-05 越权与限流

- 未登录访问 `/api/user/**` → 401
- USER 访问 `/api/admin/**` → 403
- 登录 20 次/分/IP、下单 POST 30 次/分/IP → 429；Redis 宕机时限流放行，正确性仍靠数据库
