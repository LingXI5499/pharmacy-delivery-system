# 简历描述与面试讲稿

禁止把本项目写成「生产级智慧医疗 / 亿级并发 / 已合规」。它是单店药房教学作品集。

## 简历可用段落（约 80 字）

基于 Spring Boot 3 与 Vue 3 的单店药房即时配送作品集：用 FEFO 批次行锁和条件更新保证库存不为负；支付/退款回调靠数据库唯一键幂等；RabbitMQ 故障时订单事务仍提交，事件经 Outbox 重放。k6 100 VU 证据见 GitHub Actions run 35088568109（目录 p95 18ms、下单 p95 32ms、对账为 0）。未使用微服务与容器编排。

## 3 分钟

**问题**：作业店容易做成可改库存字段的商城，并发一打就超卖。

**约束**：单店、虚构数据、单体、MySQL 为真相。

**方案**：可售批次四条件 + FEFO 锁行；`medicine.stock` 只读聚合；支付回调状态短路。

**失败方案**：Redis 当库存账本、事务里等 RabbitMQ。

**测试**：库存并发集成测试；P1 k6 对账。

**结果**：Actions 报告对账四项为 0；消息路径未纳入那次 p95。

## 5 分钟

在 3 分钟上增加：

- 处方：Tika 真类型、非静态目录、越权 404
- 采购：DRAFT 审批锁行，收货才入库
- 可靠事件：Modulith JDBC + Inbox
- 覆盖率：Q3 PR #11 本机 94%，**以 CI 为准，未合并不算**

## 10 分钟

按「一条请求」讲：`Idempotency-Key` → 锁用户 → OTC 预占 → Outbox → 模拟支付 confirmSale → 接单打包派送。穿插 EXPLAIN 前后（V5 目录索引）和限流如何影响 k6 写入 VU。结尾主动说岗位差距：没有真实值班、没有多机房、没有医疗资质。
