# 产品需求：速安药房即时配送（教学作品集）

## 问题

单店药房要同时管采购进货、批次效期、处方审核、下单支付和短途配送。常见课程作业只做 CRUD 购物车，无法解释库存为何不为负、支付回调为何不重复出库、消息队列宕机为何不能回滚已成功的订单。

## 目标用户（虚构）

| 角色 | 目标 |
|---|---|
| 顾客 USER | 浏览可售药品、下单、模拟支付、看配送状态 |
| 药师 PHARMACIST | 审核处方文件，通过后才预占库存 |
| 采购 PURCHASER | 维护供应商、提交采购单 |
| 管理员 ADMIN | 审批采购、履约接单打包派送、用户与药品资料 |
| 仓库 WAREHOUSE | 分批收货、近效期、盘点与只读对账 |

## 范围内

- Java 17 / Spring Boot 3.5 模块化单体 + Vue 3 前台与角色工作台
- FEFO 批次库存、`inventory_ledger` 只追加
- JWT + Refresh 轮换、处方真实内容检测
- 模拟支付/退款，数据库唯一键幂等
- Redis 仅缓存/限流/可降级；MySQL 守最终正确性
- Flyway V1～V5（已发布版本不可改）

## 范围外

- 真实支付、医保、医院、患者数据和诊疗
- Spring Cloud、微服务、Docker、Kubernetes、Elasticsearch
- 多门店、分仓、医保结算、GSP 合规认证

## 成功标准（必须可引用证据）

- 订单、预占、流水同事务提交或回滚
- 可售批次：未过期 + 合格 + 可销售 + 可用量 > 0
- 未登录 401、角色不足 403、越权资源不泄露存在性
- 性能数字只引用 [P1 报告](reports/p1-performance.md)
- 覆盖率只引用同一 SHA 的 CI；Q3 见 PR #11，未合并前不算达标
